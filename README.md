# Age Calculator

A simple web app built with **HTML, CSS, and JavaScript** that calculates your exact age in **Years, Months, and Days** based on your Date of Birth.


## Features
- Enter your Date of Birth and instantly see your age.
- Displays results in a clean card layout:
  - Years (big and bold)
  - Months and Days side‑by‑side
- Responsive design with modern UI styling.


## Tech Stack
- **HTML5** – structure
- **CSS3** – styling and layout
- **JavaScript (ES6)** – age calculation logic
